# FASTLIFE QUANT AI
#
# Architecture developpement plan for the full bot.
#
# Phases covered in the scaffold:
# - 1: data foundation (existing)
# - 2: market pipeline (existing)
# - 3: ICT/SMC engine (core events, detectors, engine)
# - 4: quant engine (metrics + result evaluation)
# - 5: risk engine (position sizing and daily risk rules)
# - 6: backtesting engine (historical simulation scaffold)
# - 7: macro intelligence (economic context)
# - 8: MT5 engine (demo-only access layer)
# - 9: API + dashboard (read-only supervisory surfaces)
#
# Critical principles:
# - Data before opinion.
# - Statistics before conviction.
# - Capital protection before performance.
# - No fake real data.
# - No live order execution.
# - No look-ahead bias in analysis logic.
# - Each detector must be explicit and explainable.
